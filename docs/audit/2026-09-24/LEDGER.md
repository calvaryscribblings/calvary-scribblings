# The Ledger — web, 24 September 2026

Read-only audit of the web repo and the live site against [`docs/PREMIUM-BAR.md`](../../PREMIUM-BAR.md).
The companion report is [`REPORT.md`](REPORT.md), the device walk list is [`WALK-LIST.md`](WALK-LIST.md),
and the saved-stories hand-off to the app session is [`HANDOFF-SAVED-STORIES.md`](HANDOFF-SAVED-STORIES.md).

**Severity:** P0 = money, data, security or launch-blocking · P1 = visible bug · P2 = premium gap · P3 = nice to have.
**Bar:** the PREMIUM-BAR line the finding fails. "—" = no bar line covers it (security or data), and the row says so.
**Evidence:** paths are relative to this folder. **‡ = held locally, not committed.** This repo is public, and those
screenshots show a founder's email address, paid or unpublished story text, or reader uids. `admin/` and `gate/` are
listed in `.git/info/exclude` on the audit machine.
**Measured vs chosen:** contrast ratios, target sizes, characters per line and lab timings were measured. The lab
network and CPU profiles copy Lighthouse's defaults: chosen, not derived. **No field (CrUX) data could be obtained** (SPD-01).

Merged duplicates: MEM-01 → MON-09 (membership return banner) · SQ-15 → ACC-02 (raw verification-mail error).
Passes (no row): My Library under Reduce Motion; the designed "No signal" page on /settings, /membership and /profile.
